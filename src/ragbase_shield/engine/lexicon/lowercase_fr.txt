# RAGbase Shield words for lower-case text (French). Written for RAGbase Shield, Apache-2.0.
# Ordinary words for the lower-case name rules (v0.4.1). A name typed in lower case has no capital to tell it from
# a common word, so these rules need more ordinary words than the rules for capitalised text. This file completes
# stopwords_fr.txt, vocab_fr.txt and common_words_fr.txt for these rules only: the other rules do not read it.
# Section "function": function words, interjections, numerals and chat abbreviations (never a name word).
# Section "persons": nouns that name a person (professions, offices, relations): ordinary words, and a cue for
# the name that follows them ("mon voisin pierre dupont").
# Section "states": adjectives that describe the person named just before them (state, mood, nationality):
# ordinary words, never a name, also before a verb ("madame seule assume").
# Section "words": other ordinary nouns, adjectives and adverbs (words of everyday and legal text, first names
# that are also words and the words that often follow them). Matching is case and accent insensitive; the rules
# also read a plural or a feminine form of a listed word. Several entries on a line.
