Bienvenue dans RAGbase Shield

Shield pseudonymise vos documents clients sur cet ordinateur avant qu'un assistant IA ne les lise, puis remet les vrais noms sur ce même ordinateur.

  • Tout reste ici. Aucune donnée n'est envoyée à RAGbase. Aucune télémétrie, aucun appel réseau.
  • Connectez un dossier dans Shield Desk, ne joignez pas le fichier au chat et ne collez pas de texte client brut dans le chat : ce qui est collé part chez l’éditeur de l’IA avant que Shield puisse agir.
  • C'est une pseudonymisation (réversible), pas une anonymisation. Relisez le texte masqué pour les cas sensibles.

L'installation se fait dans votre dossier personnel, sans mot de passe administrateur. Shield Desk démarre ensuite à chaque ouverture de session ; son icône est dans la barre des menus.

English: Shield masks client data on this computer before an AI assistant reads it. Nothing is sent to RAGbase, no telemetry. It installs in your own folder without an administrator password and runs Shield Desk at login, with an icon in the menu bar.
