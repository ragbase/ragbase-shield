#    and the few v0.1 references the reason names.

#    of the 56 benchmark first names and nicknames that v0.2 missed: they were not written from a miss list. Each
#    reason names the language or region, and a public macOS word list that also holds the name when one does.
#    The strict choice (remove these names from the lexicon, then measure again) stays open (SCOREBOARD section 15).
# A detection-lexicon entry that is a gold value and fits none of these rules is NOT listed here: the audit keeps
